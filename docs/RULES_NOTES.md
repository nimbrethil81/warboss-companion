# Rules notes

Verified facts from the Kings of War rules that the code depends on, recorded so the same
question doesn't have to be asked twice.

## What belongs here

- The **specific values or behaviours a feature actually needed** — the number of turns, what a
  Nerve test rolls and adds, how many artefacts a unit may carry.
- Written **in our own words**, with a citation to where it came from
  (`Mini-rulebook, "Nerve"` / `FAQ v1.0, Q7`).
- Added **when a feature needed it**, not in advance.

## What does not belong here

- **Quoted rulebook text.** Cite the section; never reproduce the sentence. This applies to
  rule text pasted into a chat to answer a question as much as to anything else.
- **Unit profiles, army lists, points values, artefact catalogues.** Those are Mantic's
  compilation. Whatever the app already carries in `data/` is the ceiling, not a precedent.
- **Systematic coverage.** Do not work through a chapter filling this in. If the file is
  growing faster than the features that needed it, that is the signal to stop.

The distinction that matters: an individual fact you need in order to write a line of code is
fine. A reproduction of the source is not — and it is the *volume* that flips one into the
other, not the wording.
